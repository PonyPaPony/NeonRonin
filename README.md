# 🗡 Неоновый Ронин

Action/Idle RPG про девушку-самурая: Неоновый Токио → Храмовый квартал → Горный пик.
Работает в браузере (ПК и телефон) и как Android-приложение (APK).

```
neon-ronin/
├─ www/                      ← сама игра (это и есть сайт)
│  ├─ index.html             ← весь код игры
│  ├─ manifest.webmanifest   ← «паспорт» веб-приложения (имя, иконка, ориентация)
│  ├─ sw.js                  ← сервис-воркер: игра работает без интернета
│  └─ icons/                 ← иконки
├─ assets/icon-only.png      ← исходник иконки для APK
├─ capacitor.config.json     ← настройки обёртки Capacitor (id приложения, имя)
├─ package.json              ← какие пакеты нужны для сборки APK
├─ scripts/patch_android.py  ← альбомная ориентация, полный экран, номер версии
└─ .github/workflows/
   ├─ android.yml            ← GitHub сам собирает APK
   └─ pages.yml              ← GitHub сам публикует веб-версию
```

## Первый запуск — шаг за шагом

### Шаг 1. Установи Git
Скачай с https://git-scm.com и установи (все галочки по умолчанию).
Проверка — открой терминал (на Windows: «Git Bash» или PowerShell) и введи:
```bash
git --version
```
Должно вывести что-то вроде `git version 2.47.0`.

Один раз представься Git’у (это подпись под твоими коммитами):
```bash
git config --global user.name "Твоё Имя"
git config --global user.email "почта@от-гитхаба"
```

### Шаг 2. Создай репозиторий на GitHub
1. github.com → кнопка **New** (или «+» → New repository).
2. Имя: `neon-ronin`.
3. Видимость: **Public**. На бесплатном аккаунте сайт GitHub Pages работает только у публичных репозиториев,
   а сборки Actions для публичных — без лимита минут. Код будет виден, но ключи подписи лежат в «секретах» — их не видно никому.
4. **Не** ставь галочки «Add README / .gitignore / license» — у нас всё уже есть.
5. Create repository. Скопируй адрес вида `https://github.com/ЛОГИН/neon-ronin.git`.

### Шаг 3. Добавь секреты подписи APK
Репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
Создай 4 секрета из файла `keystore-secrets.txt` (он пришёл отдельно, в проект его **не** клади):
`KEY_ALIAS`, `KEYSTORE_PASSWORD`, `KEY_PASSWORD`, `KEYSTORE_BASE64`.

> Зачем: Android разрешает ставить новую версию поверх старой, только если обе подписаны одним ключом.
> Без секретов соберётся отладочный APK, и каждое обновление придётся ставить через удаление.

### Шаг 4. Включи GitHub Pages
**Settings** → **Pages** → **Source: GitHub Actions**. Больше ничего не нужно.

### Шаг 5. Отправь проект на GitHub (первый push)
Распакуй архив, открой терминал **в папке проекта** и выполни по одной строке:
```bash
git init                        # превращаем папку в git-репозиторий (создаётся скрытая папка .git)
git add .                       # «кладём в корзину» все файлы для будущего снимка
git commit -m "Первая версия"   # делаем снимок (коммит) с подписью
git branch -M main              # называем основную ветку main
git remote add origin https://github.com/ЛОГИН/neon-ronin.git   # говорим, куда отправлять
git push -u origin main         # отправляем; -u запоминает связь, дальше хватит просто git push
```
При первом `push` откроется окно входа в GitHub — войди через браузер.

### Шаг 6. Дождись сборки
Вкладка **Actions** — там две задачи: «Сборка APK» (~5–8 минут) и «Веб-версия» (~1 минута).
Зелёная галочка — готово, красный крестик — пришли мне текст ошибки (кликни по задаче → по красному шагу).

- **Веб-версия:** `https://ЛОГИН.github.io/neon-ronin/`. На телефоне в Chrome: меню ⋮ → «Добавить на главный экран».
- **APK:** вкладка **Releases** (справа на главной странице репозитория) → `NeonRonin-1.N.apk`.

### Шаг 7. Установи APK на телефон
1. Открой ссылку на релиз **на телефоне** и скачай `.apk`.
2. Нажми на скачанный файл. Android спросит разрешение «Установка из неизвестных источников»
   для Chrome или «Файлов» — разреши для этого приложения.
3. Установить → Открыть. Игра запустится во весь экран, горизонтально.
   Минимальная версия Android — 6.0.

### Шаг 8. Перенеси прогресс
Сохранение из браузера в приложение само не переходит — это разные «хранилища».
В старой версии: **☰ Меню** → «Создать код» → «Поделиться» (например, себе в Telegram).
В приложении: **☰ Меню** → вставить код → «Загрузить из кода» (нажать дважды).

## Как выпускать обновления
Когда получишь новый `index.html`:
```bash
# 1. замени файл www/index.html новым
git status                         # покажет, что изменилось (красным — изменённые файлы)
git add www/index.html             # добавляем изменение в будущий снимок
git commit -m "Патч: питомцы"      # снимок с понятным описанием
git push                           # отправляем — GitHub сам соберёт новый APK и обновит сайт
```
Через ~5–8 минут в Releases появится новая версия: скачай и установи **поверх** старой — прогресс сохранится.

Полезные команды:
```bash
git log --oneline     # история коммитов
git diff              # что именно поменялось (до git add)
```

## Если что-то пошло не так
- **«Приложение не установлено» при обновлении** — старая версия подписана другим ключом
  (например, собрана до добавления секретов). Перенеси прогресс кодом, удали игру, поставь новую.
- **Сборка APK красная на шаге «Иконки приложения»** — это не страшно, шаг необязательный: будет стандартная иконка.
- **Сайт показывает старую версию** — обнови страницу ещё раз: новая версия подтягивается при следующем открытии.
