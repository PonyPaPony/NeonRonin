# 🗡 Неоновый Ронин

Экшен-RPG с элементами idle про девушку-самурая в неоновом киберпанк-Токио.
Игра целиком написана на HTML5 Canvas в одном файле. Работает в браузере на ПК и телефоне,
есть Android-приложение (APK).

**▶ Играть в браузере:** https://ponypapony.github.io/NeonRonin/
**📱 Скачать APK:** [Releases](https://github.com/PonyPaPony/NeonRonin/releases/latest)

---

## Об игре

Героиня проходит три карты: **Неоновый Токио → Храмовый квартал → Горный пик**.
На каждой карте четыре зоны с боссами, свои враги и стихии.
Атака автоматическая, игрок управляет движением, рывками и навыками.
Есть авто-охота, так что игру можно оставить фармить.

**Что внутри**
- **Кузница:** ранги и уровни катаны и доспеха, зачарования, бижутерия (кольцо, браслет, ожерелье), древняя кузница.
- **Душа:** уровни души и ветки пассивных бонусов.
- **Древо Жизни:** стихийные сопротивления, меткость, пробивание, блок, защита от проклятий и яда.
- **Испытания** с модификаторами, доска заданий, проклятия, лавка, свиток воскрешения.
- **Класс Они:** собери четыре куска маски, сбрось прогресс снаряжения и сражайся парными катанами с режимом ярости.
- **Питомцы:** кот, кицунэ, тануки, панда, бесёнок и редкая радужная пони. У каждого своё дерево навыков. Яйца добываются в квестах Питомника.
- **Перенос сохранения** между устройствами по текстовому коду, без серверов и регистрации.
- **Работает без интернета:** после первого открытия игра запускается офлайн (PWA).

**Доступность и производительность**
- Три уровня графики и режим «Авто», который сам снижает качество на слабых устройствах.
- **Безопасность вспышек:** никаких белых вспышек на весь экран и мерцаний чаще 3 раз в секунду.
  В меню есть настройка «Снизить яркие эффекты» для людей, чувствительных к миганию.

## Установка APK

1. Откройте [последний релиз](https://github.com/PonyPaPony/NeonRonin/releases/latest) на телефоне и скачайте `NeonRonin-1.N.apk`.
2. Разрешите установку из неизвестных источников для браузера или «Файлов», когда Android спросит.
3. Новые версии ставятся поверх старой, прогресс сохраняется.

Нужен Android 6.0 или новее. Сохранение из браузера в приложение само не переходит:
в браузере **☰ → Создать код**, в приложении **☰ → вставить код → Загрузить из кода**.

## Как устроен проект

```
www/                      — сама игра (публикуется как сайт)
├─ index.html             — весь код игры: движок, отрисовка, интерфейс
├─ manifest.webmanifest   — описание веб-приложения
├─ sw.js                  — сервис-воркер для офлайн-режима
└─ icons/
assets/icon-only.png      — исходная иконка для APK
capacitor.config.json     — настройки Capacitor (обёртка для Android)
package.json              — зависимости для сборки APK
scripts/patch_android.py  — альбомная ориентация, полноэкранный режим, номер версии
.github/workflows/
├─ android.yml            — сборка и подпись APK, публикация в Releases
└─ pages.yml              — публикация веб-версии на GitHub Pages
docs/MAINTAINING.md       — как выпускать обновления
```

**Технологии:** чистый JavaScript и Canvas 2D без фреймворков и сборщиков; PWA;
[Capacitor 7](https://capacitorjs.com/) для Android; GitHub Actions для сборки и публикации.

## Запуск локально

Сборка не нужна: откройте `www/index.html` в браузере.
Чтобы проверить офлайн-режим, сервис-воркеру нужен локальный сервер, например:

```bash
cd www
python -m http.server 8000
# затем откройте http://localhost:8000
```

## Сборка и выпуск

Push в `main` с изменениями в папке `www/` запускает две задачи GitHub Actions
(правки только в документации их не запускают):
- **Веб-версия** — публикует папку `www/` на GitHub Pages (около минуты);
- **Сборка APK** — собирает подписанный APK и создаёт релиз `v1.N` (5–8 минут).
  Её также можно запустить вручную: Actions → Сборка APK → Run workflow.

Для подписи APK в настройках репозитория нужны секреты `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`,
`KEY_ALIAS` и `KEY_PASSWORD`. Без них соберётся отладочный APK, который нельзя ставить поверх
подписанной версии. Пошаговая инструкция — в [docs/MAINTAINING.md](docs/MAINTAINING.md).
